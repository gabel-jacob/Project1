Walnut & Maple Wave Shelf

A furniture-scale fabrication project exploring abstract wave geometry, Rhino modeling, micro-scale 3D printing, CNC cutting, hand-built legs, and joinery through band saw and chisel work.

Furniture Design Rhino CNC Router 3D Print Prototype Joinery

Concept

The idea began as an entryway table or bookshelf with abstract wave details, possible inlaid utility elements, and a handcrafted structure. The goal was to translate a sketch into a physical object using both digital fabrication and traditional shop tools.

Prototype

I modeled the piece in Rhino and created a micro-scale 3D print to study the form, proportions, and possible issues before committing to full-scale cutting.

Fabrication

The process included CNC-cut wave geometry from Rhino files, testing tabletop layouts, making legs by hand, test fitting, and using the band saw and chisel to develop joinery.

Design questions

This project pushed me to think about visibility, usefulness, material choice, machine constraints, and how much of a physical object should be digitally fabricated versus hand-made.

Role

Sketching, Rhino modeling, 3D print prototyping, CNC setup, leg fabrication, joinery testing, and documentation.
