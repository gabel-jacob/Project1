Systems Programming

A collection of lower-level programming projects focused on memory management, pointer arithmetic, x86-64 debugging, and PostgreSQL internals.

CGDBPostgreSQLMemory AllocationDatabase Internals

Memory allocator

I implemented an explicit-list memory allocator with available and used block lists, block splitting, coalescing, headers, footers, and pointer arithmetic.

PostgreSQL labs

I worked inside PostgreSQL internals to experiment with buffer replacement behavior and optimizer join-path selection using C source changes and runtime logging.

Debugging

These projects required careful use of GDB, C memory layout reasoning, build systems, compiler errors, and step-by-step validation.
