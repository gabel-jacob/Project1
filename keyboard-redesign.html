Walnut Keyboard Redesign

A second keyboard case project focused on improving material strength, tolerances, internal clearance, gasket mounting, and the overall product language of the original wooden keyboard.

WalnutRhinoRhinoCAMCNCTolerance Testing

Why redesign?

After the first wooden keyboard case, I identified opportunities to improve the construction: closure behavior, cleaner chamfers, PCB room, and more accurate gasket mount height.

Design changes

The redesign explored walnut, a more refined case profile, improved alignment between halves, and a more intentional exterior inspired by natural forms.

Prototype findings

Test fitting revealed tolerance problems that CAD alone did not show. That failure became the key learning moment for the next set of fabrication decisions.
