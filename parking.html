GopherParkLive

A campus parking assistant concept focused on reducing parking uncertainty through research, prototyping, usability testing, and iterative interface design.

UX Research User Testing Figma Accessibility Product Strategy

Problem

Students and staff often need to make parking decisions under time pressure, especially around class schedules, campus events, weather, and peak demand. The goal was to reduce uncertainty before users arrived on campus.

Research

The project focused on understanding how users evaluate parking options, what information they trust, and how alerts or recommendations could reduce stress. Research helped define the core user need: faster decision-making with clearer parking availability signals.

Testing

User testing helped evaluate task flow, label clarity, feature discoverability, and whether the interface communicated parking availability quickly enough. Feedback informed changes to page labels, button hierarchy, and route guidance.

Design focus

The interface was designed around quick scanning: users should be able to see affected areas, parking difficulty, and suggested routes without reading too much detail while they are trying to get to campus.

Role

UX research, concept development, Figma prototyping, usability testing, interface iteration, and design presentation.

Reflection

This project helped me practice the full UX process: identifying a user problem, building a prototype, testing with users, and turning feedback into design changes.
